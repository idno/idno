Legacy tables

When this site was upgraded from Idno 1.x, the tables of the old database were kept, renamed legacy_ followed by their old name. The site no longer reads them. Keep them until you are sure the upgrade went well; then you can delete them here.

Tables created by an old Idno process

These tables have the names of the Idno 1.x tables, but they were created after the upgrade, by a process still running the old version of Idno (a queue or cron service, for example). Nothing in them is part of this site, and the site never reads them. Stop that process. These tables are not deleted from here.
