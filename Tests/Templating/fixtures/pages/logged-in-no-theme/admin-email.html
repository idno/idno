Email settings

Idno tries to send email using your server's default email settings. If you'd like it to do something else - for example, if you'd like to send email using an external provider - enter the new SMTP settings below.

After changing the mail settings, restart the queue worker: the mails it sends (the export and import results) use the settings it read when it started.

Fill in the site email address if you would like your site to send email.

Site email address

This is the address that every email will be sent from.

You can often leave the following settings blank. However, you may wish to set them if you're using a third-party service to send email.

SMTP host

This is the address of the server that will send email for you.

SMTP username

If your mail server needs a username, enter it here.

SMTP password

If your mail server needs a password, enter it here.

SMTP port

This is normally 25 or 587.

Secure connection

Select yes if you use secure logins to your mail server.
