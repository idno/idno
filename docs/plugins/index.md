# Idno Plugins

* [Official plugins](project.md): the plugins that come with Idno, and what each one does.
* [Community plugins](community.md): plugins written by other people.
* [Plugins and themes](../admin/plugins-and-themes.md): turning plugins on and off, and installing new ones.
* [Writing plugins](../developers/plugins/index.md): making a plugin of your own.
