# Idno Documentation

[Idno](https://idno.co) is an open source publishing platform for one person or a group. You publish notes,
articles, photos, events, bookmarks and more on a site you own, and your posts reach people wherever they are:
through feeds, the IndieWeb, the Fediverse and the AT Protocol.

This is the documentation for people who install, run and extend Idno.

## About the name

The project began as Idno, was called Known for some years, and is Idno again. You will still meet the name
Known in a few file names, settings and headers, which keep working. In these pages, and in new code, it is Idno.
